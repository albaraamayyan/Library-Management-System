# 📚 Library Management System

مشروع نظام إدارة مكتبة إلكترونية، صممت وقسمت قاعدة بياناته باستخدام لغة SQL عشان تنظم بيانات الكتب، المؤلفين، والأعضاء وحركات الاستعارة بشكل مرتب وسليم.

## مراحل العمل على المشروع:
1. تحليل المتطلبات: حصرت الأشياء الأساسية اللي يحتاجها النظام (الكتب، المؤلفين، الأعضاء، وسجل الاستعارة) عشان أضمن متابعة حالة الكتب إذا كانت معارة أو متاحة.
2. التصميم المفاهيمي: رسمت علاقة البيانات وارتباط الكيانات ببعضها (مثل ارتباط الكتاب بمؤلف، واستعارة العضو للكتاب).
3. التصميم المنطقي: حولت هذا التصميم إلى جداول واضحة وحددت المفاتيح الأساسية والأجنبية عشان تربط الجداول ببعضها بدون أخطاء.
4. التصميم الفيزيائي: اخترت أنواع البيانات المناسبة لكل عمود وضفت فهارس على أعمدة البحث عشان أضمن سرعة وكفاءة استرجاع البيانات.

## الجداول المستخدمة في قاعدة البيانات:
* **Authors:** لتسجيل أسماء المؤلفين ونبذة عنهم.
* **Books:** خاصة بالكتب وترتبط بالمؤلفين عبر مفتاح أجنبي.
* **Members:** بيانات الأعضاء المسجلين في المكتبة.
* **Borrowings:** جدول خاص بتتبع عمليات الاستعارة وتاريخ الإرجاع.
